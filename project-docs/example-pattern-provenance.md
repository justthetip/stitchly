# Stitchly starter pattern provenance

The bundled “Stitchly Starter Headband” PDF is original first-party demonstration content created for Stitchly. Its pattern copy, layout, and artwork are owned by the Stitchly project and may be distributed with the product for onboarding and evaluation.

The basket illustration is the project-owned transparent splash artwork at `project-docs/splash-assets/LaunchIconTransparent.png`. The PDF contains no customer data and no third-party pattern content.

The pattern is intentionally short, but includes materials, a repeated row range, shaping, finishing, and source labels so that import review, project creation, notes, and the focused reader can all be tested.
